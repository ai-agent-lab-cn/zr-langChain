# 星河工单助手：项目概览（虚构教学样例）

> 本文件是为第六章 RAG 教学编写的虚构知识资料，不代表真实企业或生产系统。

## 项目目标

星河工单助手是一个用于演示企业客服场景的虚构项目。它将收到的文字工单按主题分类，方便客服人员查看分类结果和处理建议。本项目强调“检索文档、确认依据、再生成回答”的工作方式。

## 支持的三类工单

当前教学版本支持三种工单分类：**账户问题、支付问题、物流问题**。账户问题包含登录困难和修改账户资料；支付问题包含支付失败和退款进度；物流问题包含包裹追踪和配送异常。

这三类是演示系统已经明确定义的工单范围。超出范围的工单可以交给人工处理，不应由 Agent 自行发明新分类或者假称它们已正式上线。
